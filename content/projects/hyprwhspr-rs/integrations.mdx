## Hyprland

Use compositor binds for capture-first recording:

```ini
bind = ALT, GRAVE, exec, hyprwhspr-rs record start
bindr = ALT, GRAVE, exec, hyprwhspr-rs record stop
bind = ALT, SPACE, exec, hyprwhspr-rs record toggle
```

This avoids exclusive keyboard grabs and lets Hyprland keep normal input behavior intact.

## Waybar

The repository ships a Waybar module and style under `config/waybar`.

```bash
./scripts/install-waybar.sh
```

The module can display recorder state and invoke the daemon controls.

## Walker And Elephant

The installer can add an experimental Walker/Elephant menu:

```bash
hyprwhspr-rs install --elephant
```

The source template lives in `config/elephant/hyprwhspr.lua`.

## Quickshell

Example Quickshell status UI files live under `docs/examples/quickshell` in the upstream repository.

Use these examples as reference material for custom desktop surfaces that need to show microphone or recorder state.
