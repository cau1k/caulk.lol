# Admin Design

- No gradients.
- No decorative backgrounds.
- Use a Vercel-like black, white, gray system.
- Use caulk green only for link affordances and small positive states.
- Nested cards are bad.
- Prefer separators, rows, and plain sections over boxed surfaces.
- Keep the sidebar close to default shadcn. Do not heavily customize it.
- Keep copy direct. No title/subtitle marketing pattern.
- Headings should name the thing: `Links`, `Security`, `Passkeys`, `API keys`.
- Body text should explain behavior or consequences only.
- Use shadcn components from `packages/ui` as vendored. Do not fork component styling for one-off effects.
